# 一、产品概述

## 1.1 产品背景

随着新能源汽车渗透率持续提升，2026年国内新能源乘用车销量突破1300万辆，公共充电基础设施需求呈现爆发式增长。然而充电体验碎片化问题依然突出：用户需在多个App之间切换才能覆盖不同运营商的充电桩，实时空闲状态不透明，支付流程繁琐，导致用户充电效率低下。

本产品旨在打造一款聚合型电动汽车充电小程序，整合主流充电运营商资源（特来电、星星充电、云快充等），以地图为核心视角，结合实时桩态、一键扫码启动、智能会员权益等功能，为新能源车主提供找桩—充电—支付—管理的全链路流畅体验。

## 1.2 产品定位

| **维度** | **描述**                        |
| ------ | ----------------------------- |
| 目标用户   | 私家新能源车主、网约车/营运车辆驾驶员、充电桩场地运营方  |
| 核心价值   | 附近充电站一图看全、实时桩态透明、扫码即充无感支付     |
| 差异优势   | 多平台桩资源聚合、PLUS会员跨站优惠、V2G碳积分体系  |
| 商业模式   | 充电服务费分成 + 会员订阅 + 广告投放 + 能量包预售 |

## 1.3 竞品参考

本文档参考了以下市场主流充电App的UI交互与功能架构进行设计：

•    特来电：PLUS会员体系、星级站评级、快慢充桩态展示

•    星星充电：聚合首页列表、满减券机制、电池管家功能

•    e充电（南方电网）：地图+列表双视图、高速路站筛选、即插即充

•    云快充：第三方订单聚合、充电能量包预购

## 3.2 页面层级结构

### 首页模块

•    地图视图：聚合标注（按运营商着色）、点击展开站详情浮层、定位按钮

•    列表视图：距离/综合/价格排序、多条件筛选（快充/慢充/免费停车/高速路站/重卡专用）

•    站点详情页：站名 + 地址 + 评分 + 快慢充桩数实时状态 + 价格 + 停车信息 + 用户评价

•    筛选面板：距离范围 + 充电速度 + 运营商 + 附加权益（PLUS会员站/停车减免/即插即充）

### 扫码充电流程

•    Step 1 扫码/输入桩号：识别桩上二维码 → 跳转充电参数确认页

•    Step 2 确认启动：选择充电模式（按金额/按电量/充满为止）→ 确认支付方式

•    Step 3 充电中：实时功率 + 已充电量 + 费用 + 预计完成时间 + 停止充电按钮

•    Step 4 完成结算：自动扣费 → 账单详情（电费+服务费明细）→ 评价 → 开票入口

### 我的页面模块

•    用户信息区：头像 + 手机号 + 会员等级徽章 + 消息通知 + 设置

•    钱包区：余额 + 充值/退款 + 卡券数量 + 能量包 + 积分

•    车辆管理：绑定车牌 + 车型识别 + 电池容量记录 + 电池卫士检测报告

•    常用工具：我的订单 / 发票管理 / 充值 / 即插即充 / 客服中心 / 收藏电站 / 意见反馈 / 无法拔枪

## 4.3 会员与权益体系

参考特来电PLUS会员体系，设计三级会员架构：

| **会员等级**  | **开通方式**     | **核心权益**                        | **月省上限** |
| --------- | ------------ | ------------------------------- | -------- |
| 普通用户      | 免费注册         | 基础充电功能、历史订单、收藏                  | —        |
| PLUS会员（银） | ¥2.9-9.9/月订阅 | 充电折扣6折起、每月满减券包×5、停车减免资格         | 约¥50     |
| PLUS会员（金） | ¥19.9/月 或 季卡 | 8折专属单价 + 月赠能量包 + 优先客服通道         | 约¥100    |
| V1/超级会员   | 年卡 ¥99-198   | 最低折扣 + 全年满减礼包 + 电池管家深度检测 + 一号多充 | 约¥158    |

能量包机制：用户可预购固定度数的充电套餐（如100度/200度），锁定当前低价，后续充电自动抵扣，适合高频用户对冲电价波动。

## 4.4 钱包与支付

•    支持微信支付 / 支付宝 / 余额抵扣 / 卡券叠加使用

•    余额充值：支持10/30/50/100/200元快捷充值，满额赠送充值金

•    优惠券：满减券 / 折扣券 / 免费停车券，支持自动匹配最优券

•    电子发票：按月汇总开具，支持个人/单位抬头，PDF下载或推送至邮箱

•    退款：余额支付部分T+1工作日退回账户余额；第三方支付原路退回

## 4.5 车辆管理

•    支持绑定多辆车，设置主车与副车

•    录入车型后自动匹配充电接口类型（国标/特斯拉/欧标），首页筛选自动适配

•    电池卫士：记录每次充电数据，分析电池健康度、容量衰减趋势，生成检测报告

•    精准推荐：根据当前车辆电量（若车辆支持API推送）智能推荐附近合适的充电站

## 4.6 碳积分与V2G

绿色能源是新能源车主的重要身份认同。产品规划碳积分体系作为长期差异化功能：

•    每次充电自动记录碳减排量（kWh × 碳排放因子），在订单页展示本次碳贡献

•    累计碳积分可兑换充电券、周边商品或捐赠公益树苗

•    V2G（车辆向电网放电）：支持具备V2G功能的车辆在用电低谷时段放电获得补贴收益

| 支付响应   | 支付结果回调 ≤ 3秒，超时自动查单            |

## 5.2 安全与隐私

•    支付数据：全程HTTPS

+ 微信支付官方SDK，不本地存储银行卡信息

•    位置权限：明确告知用途，仅在使用地图功能时请求，不后台持续采集

•    车辆数据：车牌号脱敏存储，API传输加密，运营方无法获取用户完整车牌

•    账户安全：支持手机号一键登录，敏感操作（退款/修改手机）需二次验证

## 6.2 关键交互说明

### 首页地图交互

•    默认进入地图视图，底部滑动面板展示附近站列表（可上滑至全屏列表）

•    地图标注点击：底部卡片展开站点摘要（站名/距离/空闲数/最低价），上滑进入详情页

•    列表与地图联动：列表滑动时地图聚焦到对应站点

### 充电中页面

•    充电中页面常驻显示，支持从通知栏点击快速回到该页

•    充电进度用环形进度条 + 百分比展示，中心显示已充电量(kWh)

•    停止充电按钮需二次确认弹窗，避免误触

### 空状态与异常处理

•    附近无充电站：展示插图 + '扩大搜索范围' 建议操作

•    网络异常：Toast提示 + 重试按钮，核心数据本地缓存兜底

•    支付失败：明确说明失败原因（余额不足/网络超时），提供切换支付方式引导

## 7.2 核心运营指标

•    DAU / MAU：日活 / 月活用户数

•    充电成功率：扫码启动后成功完成充电的比例（目标 ≥ 95%）

•    ARPU：每月每用户平均充电消费金额

•    会员转化率：注册用户中开通PLUS会员的比例（目标 ≥ 12%）

•    NPS：用户净推荐值，通过充电完成后的评价采集

•    平均等待时间：用户到达充电站到开始充电的平均时长
