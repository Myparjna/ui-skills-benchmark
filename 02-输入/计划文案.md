# 前言为什么要做

苦于大模型做的设计的网页不好看，我决定使用一些skills来强化它们的前端设计能力。打好这个基础，我之后做的网页才有意义。不然到时候又得重做。

别人做的所有的测评都太过于零散，一般单独就讲一个skills多么多么厉害，或者就3、4个skills对比下多么厉害，不够全面。

我打算自己选取9个热门的前端设计skills，配合kimi2.6、glm5v、mimo v2pro、gemini3.1四款设计网页对比一下美观度。

一共进行9x3x3个网页的设计，包含公司官网landing page，后台管理页面，手机app页面设计。

制作不易不废话开做。

## 第七款 [frontend-design by pbakaus/impeccable](https://skills.sh/pbakaus/impeccable/frontend-design)

**它是什么**

- Anthropic frontend-design 的“加强版/工程版”。最大的变化不是审美词，而是：
  
  - **必须先拿到 Design Context**（受众、用例、品牌人格）
  
  - 如果没有，就要求读取 `.impeccable.md`，再不行必须跑 `/teach-impeccable`。

**它更像什么**

- “一套专业设计评审+落地指南”，而不是给你一个固定风格。

**模板情况**

- 没有直接的整站模板，但它把内容拆成很多 reference（typography/color/spatial/motion/interaction/responsive/ux-writing），相当于“资料库型模板”。

**适用**

- 你做的是 **长期产品/多页面系统**，最怕“第一屏好看、后面失控”。它会逼你先定调、再落地。

npx skills add https://github.com/leonxlnx/taste-skill --skill design-taste-frontend

## 第八款 https://skills.sh/nuxt/ui/nuxt-ui

vue版本的next.js **它是什么**

- Vue/Nuxt 的组件体系：125+ 组件、统一 theming、iconify、form validation、overlays/toasts、shortcuts。

**模板情况（非常强）**

- 预置 Layout references：Page/Dashboard/Docs/Chat/Editor。

- 官方 starter templates 很多（SaaS/Landing/Docs/Portfolio/Chat/Editor/Changelog…）。

**审美取向**

- 默认是“干净、体系化”，真正差异化来自你是否用它的 theming/semantic utilities 去做品牌定制。

**适用**

- 你要快速堆出一个 Vue/Nuxt 产品，同时想要 a11y/组件质量稳定；也适合团队统一组件与主题。
- npx skills add https://github.com/nuxt/ui --skill nuxt-ui
