Semantic Design Language for Shared Mobility Operations

1. Visual Theme & Atmosphere

This design system embodies an atmosphere of industrial precision and operational efficiency. The dark theme reduces eye strain during extended monitoring sessions, while high-contrast accent colors ensure critical information is immediately visible. The visual language combines the systematic clarity of data visualization with the urgency of real-time operations. Typography favors monospace fonts for data readability and maintains a clinical, no-nonsense aesthetic appropriate for mission-critical systems.

2. Color Palette & Roles

#0A0A0A

Deep Black

Primary background color. Reduces eye strain during extended monitoring. Creates depth for data visualization.

#FF6B35

Alert Orange

Primary accent for actions, alerts, and interactive elements. Commands attention while maintaining operational warmth.

#00FF88

Neon Green

Success states, active indicators, and positive metrics. High visibility against dark backgrounds.

#0088FF

Electric Blue

Informational states, secondary actions, and data visualization. Provides contrast to primary orange.

4. Component Stylings

Buttons

Buttons use 2px border radius for sharp, industrial appearance. All buttons include uppercase text with wide letter spacing for improved scannability.

Data Display

Data items feature left border accent for visual hierarchy. Monospace fonts ensure consistent alignment for numerical data.
