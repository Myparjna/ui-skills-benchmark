# 场景简述：星空航空官网 (airline)

## 一句话定位
高端国际化航司官网，安全、舒适、准时的飞行体验。

## 关键产品
- 公司：星空航空 Skystar Airlines
- 总部：杭州萧山国际机场
- 成立：2008 年
- 国内航线：82 城
- 国际目的地：47 个亚太及欧洲枢纽
- 日均航班：600+
- 累计安全飞行：1200 万小时
- 连续 16 年零重大事故

## 必须覆盖的内容板块
1. **顶部导航**：首页 / 航班查询 / 目的地 / 服务与礼遇 / 常旅客计划 / 关于我们
2. **Hero 横幅**：主标题「每一次起飞，都是一次全新的抵达」+ 副标题 + 航班搜索栏（出发/到达/日期/舱位/乘客数/搜索按钮）
3. **6 大卖点卡片**（Why Choose）：安全第一、广泛航线、客舱体验、云端餐饮、数字化、特殊关怀
4. **限时优惠 Banner**：夏季出行季（杭州-三亚 ¥399 / 杭州-大阪 ¥1299 / 杭州-伦敦 ¥3899）
5. **精选目的地**（5 城市卡片）：三亚 / 成都 / 东京 / 迪拜 / 巴黎
6. **星辰会员计划**（4 等级表）：银卡 / 金卡 / 白金卡 / 钻石卡
7. **服务与礼遇**：特殊旅客关怀、宠物随行计划
8. **企业商务服务**：Skystar Business
9. **Footer**：联系方式、社交媒体、APP 下载、法律声明

## 关键文案/数据
- 主品牌色：深蓝 + 星空渐变（#0B1F3A → #1E3A8A）
- 字体：高端无衬线（Inter / Noto Sans SC）
- 文案需真实，不可空泛
- 机型：波音 787 梦想客机、空客 A320neo
- 客服：智能客服"星星"，中英日韩四语

## 设计风格倾向
- 高端大气、星空主题、蓝色系
- 大 Hero 视觉 + 大量留白
- 卡片化、网格化布局
- 桌面端 1440×900 为主
