# 场景简述：电动车充电桩小程序 (ev_charging)

## 一句话定位
聚合型电动汽车充电小程序，找桩—充电—支付—管理全链路体验。

## 关键产品
- 平台：微信小程序 / 支付宝小程序
- 目标用户：私家车主、网约车司机、长途出行用户、场地运营方
- 核心场景：附近快充站、扫码启动、PLUS 会员跨站优惠、V2G 碳积分

## 必须覆盖的内容板块（按 PRD 优先级）
1. **顶部状态栏 + Header**：定位、Logo、搜索入口
2. **Banner 活动区**：限时优惠、PLUS 会员推广
3. **快捷入口网格**：附近桩、扫码充电、订单、客服（4-6 个 icon + 文字）
4. **地图视图**（核心，页面中心）：附近桩点标记、聚合气泡、当前定位、筛选按钮
5. **附近站点列表**：3-5 个站点卡片（距离、空闲桩数、价格、评分、标签如"快充""慢充""24h"）
6. **PLUS 会员 / 优惠券板块**：3 张卡片
7. **底部 TabBar**（5 个）：首页、活动、扫码（中心大按钮）、订单、我的
8. **充电进度卡片**（可选，悬浮层）：实时功率、电量、预计完成

## 关键数据/文案（可从 PRD 提取）
- 运营商聚合：特来电、星星充电、云快充、国家电网
- 用户规模：2026 年国内新能源乘用车销量突破 1300 万辆
- 价格区间：快充 1.2-1.8 元/度，慢充 0.6-0.9 元/度
- 充电功率：快充 60-120kW，超充 250kW+
- 用户旅程文案：发现需求 → 筛选决策 → 导航 → 开始充电 → 等待 → 支付 → 评价

## 设计风格倾向
- 微信小程序风格：圆角 8-12px，主色可用 #00C853（绿色）或 #2563EB（蓝）
- 移动端 375×812（iPhone）为主
- 卡片化、地图为主视觉、TabBar 固定底部
