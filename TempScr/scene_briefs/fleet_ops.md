# 场景简述：共享两轮城市运营管理后台 (fleet_ops)

## 一句话定位
城市级共享两轮（自行车/电单车）综合运营管理后台，覆盖人-车-场-单-数全链路。

## 关键产品
- 业务：单城 2-3 万辆共享自行车/电单车（含可换电车型）
- 用户角色：城市运营经理 / 调度主管 / 运维人员 / 客服风控 / 数据分析
- 竞品参考：Joyride Fleet Management、Movium、Hergele、BlueMobility Manager

## 必须覆盖的内容板块
1. **顶部 Header**：Logo、城市切换、角色切换、通知、搜索、用户头像
2. **左侧 Sidebar 菜单**（9 项）：仪表盘 / 实时地图 / 车队管理 / 电池管理 / 调度中心 / 工单 / 合规监管 / 数据分析 / 设置
3. **KPI 卡片**（顶部 4 块）：总车辆数、在线车辆、低电车辆、今日告警
4. **实时地图**（核心，页面中心）：车辆点/聚合、围栏（停车区/禁停区/限速区）、告警标记、热力图
5. **趋势图表**（3-4 个）：7/30 天订单量、营收、告警数、运维里程
6. **工单列表**：报修 / 巡检 / 调车 / 回收 / 换电（5-8 条，含状态、负责人、SLA）
7. **异常告警面板**：低电 / 越界 / 长时间静止 / 故障（每类 1-2 条）
8. **站点/围栏分布**：Top 5 热点站点、停车桩使用率
9. **合规监管**：MDS/GBFS 数据同步状态、政策规则落地

## 关键数据/指标
- 车辆数：20,000-30,000
- 高峰前 60 分钟热点区域可用车覆盖率 ≥ 90%
- 越界/禁停违规响应时长 P90 ≤ 10 分钟
- 单车单日运维里程下降 15%
- 低电告警阈值：电量 < 20%

## 设计风格倾向
- Dashboard 风格：左侧 Sidebar + 右侧主区域
- 暗色或浅色高端 SaaS 风格
- 数据密度高、图表丰富
- 桌面端 1440×900 为主
- 主色：蓝色（运营专业感）或深绿色（合规）
