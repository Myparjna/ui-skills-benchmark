Semantic Design Language for Luxury Airline Experience

1. Visual Theme & Atmosphere

This design system embodies an atmosphere of understated luxury and timeless elegance. The visual language combines the refinement of high-end hospitality with the precision of aviation technology. Deep navy backgrounds evoke the night sky, while champagne gold accents add warmth and sophistication. The aesthetic balances classical proportions with contemporary minimalism, creating an experience that feels both prestigious and approachable.

Typography plays a crucial role in establishing the premium feel. The display font (Cormorant Garamond) provides classical elegance for headings, while the primary font (Montserrat) ensures modern readability for body text. Generous whitespace and deliberate pacing create a sense of calm and order throughout the experience.

2. Color Palette & Roles

4. Component Stylings

Buttons

Buttons use uppercase text with wide letter spacing for premium feel. No border radius maintains classical elegance. Gold gradient provides visual richness.

Cards / Containers

Cards feature ivory backgrounds with subtle borders. Hover states add elevation and gold border accent for interactive feedback.
