本项目横向对比 **9 个 AI 模型** 在前端设计 skill 驱动下的页面生成效果。

- **测试场景**: 3 个产品场景（官网 / 小程序 / 后台）

### 3.5 React+Babel 白屏修复方案
GLM 5.2 的 design-taste-frontend 页面使用 React+Babel standalone，Babel 自动 JSX runtime 会尝试 `import { jsx } from "react/jsx-runtime"` 但浏览器中无此模块，导致白屏。

修复方案：
1. 注入 importmap shim：`<script type="importmap">{"imports":{"react/jsx-runtime":"data:text/javascript,export const jsx=React.createElement;..."}}</script>`
2. 将所有 `<script type="text/babel">` 转为 `<script type="text/babel" data-type="module">` 让 Babel 输出模块脚本
3. 等待 `#root` innerHTML > 500 后再截图
